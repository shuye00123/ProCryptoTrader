### 任务5.2: 更新API文档 ✅

**文件**: `docs/API.md`

**更新内容**:

#### 1. 核心数据模型章节（新增）
```python
@dataclass
class Kline:
    """1秒K线数据结构"""
    symbol: str
    open: float
    high: float
    low: float
    close: float
    volume: float                    # ✅ 真实1秒K线总成交量
    timestamp: datetime = None

    # 自动计算属性
    price_change: float
    price_change_pct: float
```

**关键说明**:
- ✅ `volume`字段是**真实的1秒K线总成交量**
- ❌ **不再使用**ticker的`last_quantity`字段（已废弃）
- ✅ 数据来源：Binance官方`@kline_1s` WebSocket流

#### 2. 数据准确性对比表（新增）

| 数据类型 | 字段 | 含义 | 示例值 | 准确性 |
|----------|------|------|--------|--------|
| **1秒K线** | `volume` | 该秒内所有成交总和 | 1234.56 BTC | ✅ 100%准确 |
| **Ticker** | `last_quantity` | 最近一次成交数量 | 0.5 BTC | ❌ 不准确 |

**差异**: 两者相差可达**2469倍**！

#### 3. WebSocket接口章节（新增）

**订阅流格式**:
```python
# ✅ 订阅1秒K线流
streams = [f"{symbol.lower()}@kline_1s" for symbol in symbols]
```

**K线消息结构**:
```json
{
  "e": "kline",
  "k": {
    "i": "1s",         // ✅ Interval: 1秒
    "v": "1000",       // ✅ Base asset volume（真实1秒总成交量）
    "x": true,         // ✅ Is this kline closed?
  }
}
```

#### 4. 策略接口章节（新增）

**MultiTimeframeKlineBreakoutStrategy**:

- 配置参数说明
- 使用示例

#### 5. 突破检测接口章节（新增）

**KlineBreakoutDetector**:
- 初始化参数说明
- 核心接口文档
- 使用示例

#### 6. 使用示例章节（新增）

**示例1**: 订阅1秒K线并检测突破
**示例2**: 回测1秒K线策略
**示例3**: 验证1秒K线数据准确性

#### 7. 数据流架构图（新增）

**实时数据流**:
```
Binance WebSocket (@kline_1s)
        ↓
BinanceWebSocketClient._process_kline_message()
        ↓
过滤未关闭K线 (k['x'] == True)
        ↓
创建Kline对象 (使用真实的volume字段)
        ↓
触发Kline回调
        ↓
KlineBreakoutDetector.detect_breakout()
        ↓
生成Signal (如果检测到突破)
        ↓
执行交易信号
```
